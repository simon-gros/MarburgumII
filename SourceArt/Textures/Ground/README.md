# Ground textures

PBR texture sets from [ambientCG](https://ambientcg.com), released under **CC0 1.0** (public domain).
Each folder holds the 2K colour and DirectX normal maps (re-saved at JPEG quality 90) and the
roughness map reduced to 1K greyscale. `MarburgumRebuildGround` imports them into
`/Game/World/Ground/Textures` (ADR-040).

| Set | Use | Source |
| --- | --- | --- |
| Asphalt031 | carriageways | https://ambientcg.com/a/Asphalt031 |
| Asphalt023S | car parks, yards and unmapped hard standing | https://ambientcg.com/a/Asphalt023S |
| PavingStones109 | pavements | https://ambientcg.com/a/PavingStones109 |
| PavingStones070 | squares and pedestrian streets (granite setts) | https://ambientcg.com/a/PavingStones070 |
| Concrete030 | kerbs and edging | https://ambientcg.com/a/Concrete030 |
| Bricks068 | steep slopes, as stone retaining walls | https://ambientcg.com/a/Bricks068 |
| Grass004 | grass | https://ambientcg.com/a/Grass004 |
| Ground037 | worn earth, leaf litter | https://ambientcg.com/a/Ground037 |
| Gravel040 | gravel paths and pitches | https://ambientcg.com/a/Gravel040 |
| Rocks022 | Drava bank and bed | https://ambientcg.com/a/Rocks022 |
