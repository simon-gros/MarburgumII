# Reference-only material

This directory represents archival material that is useful to Marburgum but should **not** be mirrored into the public Git repository by default.

The generated `INDEX.md` is a browsable view of `../../CATALOG.csv`: it preserves catalogue IDs, dates, locations, rights states and source links for restricted, uncertain and collection-level material.

Use the source link to inspect the item, then store a permitted local research copy under `~/marburgum-data/art-reference/` if needed. Do not commit newspaper scans, broadcast captures, archive downloads or CC-BY-NC material here merely because they are accessible online.
